

  # CIVORA – Community Development Events Platform

  **Small Acts. Stronger Communities.**

  A community-driven platform connecting people with meaningful initiatives and local volunteering opportunities.

  🌐 **Live Website:** [Visit CIVORA](https://civora-social-events-dot-com.vercel.app)


---

## ✨ Features

### 🌍 Discover Upcoming Events

Explore a collection of upcoming community development events, including environmental cleanups, tree plantations, blood donation campaigns, educational initiatives, and social welfare activities. Users can browse events, search by keywords, filter by category, and find opportunities that match their interests.

### 📝 Create and Organize Events

Authenticated users can create their own community events by providing an event title, description, category, location, date, and image URL. Each event is associated with its creator, allowing organizers to manage their initiatives and encourage others to participate.

### 🤝 Join Community Events

Users can join events that interest them and become part of meaningful community initiatives. The platform records participation details and prevents users from joining the same event multiple times, helping maintain organized participation records.

### 📋 Manage Created Events

Event organizers can access a dedicated dashboard to view and manage the events they have created. They can update event information or delete events when necessary, while access restrictions ensure that users can manage only their own events.

### 📅 Track Joined Events

Users can view all the community events they have joined from a dedicated Joined Events page. Each entry provides important information such as event details, scheduled dates, locations, and joining information for convenient tracking.

### 🔐 Secure Authentication System

CIVORA provides an authentication system using Better Auth with email and password credentials. Protected features require authenticated access, while JWT-based token verification helps secure private API endpoints and restrict unauthorized operations.

### 📱 Responsive User Interface

The platform is designed to provide a consistent browsing experience across desktops, tablets, and mobile devices. Its clean layout, accessible components, and responsive navigation make discovering and managing community events convenient on different screen sizes.

### 🌙 Dark and Light Theme

Users can switch between light and dark themes according to their preferences. The theme system maintains consistent styling across the platform, including navigation, event cards, forms, dashboards, and other interface components.

### ⚡ Recent Upcoming Events

The homepage highlights upcoming community events so visitors can quickly discover opportunities to participate. Events are displayed dynamically based on their scheduled dates, ensuring that expired events are excluded from upcoming event listings.

## 🏗️ Project Structure

The application follows a frontend-backend architecture, where the Next.js frontend communicates with an Express.js REST API. MongoDB is used for persistent data storage, while authentication and authorization mechanisms protect user-specific operations.

---

## 🎯 Project Purpose

CIVORA aims to make community participation more accessible by bringing organizers and volunteers together through a centralized digital platform. By simplifying event discovery, organization, and participation tracking, it encourages individuals to contribute to meaningful social initiatives and build stronger communities.
